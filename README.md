# Portfolio M7 — AlkeWallet2 Case Study

Portafolio web personal con sección de caso de estudio técnico: **AlkeWallet2**, billetera digital Android desarrollada en Kotlin con arquitectura MVVM + Repository.

## Stack Técnico

- **HTML5** — Semántica
- **CSS3** — Variables, Flexbox, Grid, media queries, Dark/Light mode
- **JavaScript** — Vanilla (toggle tema, menú mobile)
- **Tipografía** — Google Fonts (Roboto + Fira Code)
- **Hosting** — GitHub Pages

## Estructura

```
portfolio-m7-alkewallet/
├── index.html          # Página principal (6 secciones + caso de estudio)
├── styles.css          # Estilos responsivos
├── script.js           # Lógica JavaScript
├── icons/              # SVGs (GitHub, Email, Favicon)
└── README.md           # Este archivo
```

## Secciones

- **~/about** — Presentación profesional
- **~/skills** — Competencias técnicas
- **~/caso-estudio** — Análisis profundo de AlkeWallet2 (7 puntos)
- **~/proyectos** — Portafolio de proyectos destacados
- **~/formacion** — Educación formal y continua
- **~/contacto** — Formulario y email directo
